# Rehan Public School Website

## Run
Open `index.html` in any modern browser.

## Included
- English / Urdu language switch
- Dark mode
- Responsive mobile/tablet/desktop design
- Home, About, Academics, Admissions, Gallery, Faculty, News, Events, Contact
- Admission and contact form validation
- localStorage admission records
- Demo Student / Parent / Teacher / Admin login
- Role-based demo dashboards
- Notice board and event cards
- Gallery filters
- Stats counters
- Toast notifications
- Floating WhatsApp button
- Back-to-top button
- Loading animation

## Demo Login
Any username and password work. Select a role to see its dashboard.

## Before publishing
Replace the sample phone, email, address, WhatsApp number, fee values, faculty data and gallery placeholders with your real school information.
For real authentication, payments, file uploads and Google Maps, connect a backend/API and use secure server-side authentication.
